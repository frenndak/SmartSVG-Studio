## 2. Contrat candidat et UX

`OCRRequest/1` (proposition hors V1) : `source_sha256:hex64`, `project_expected_sha256:hex64`, `roi_oriented_px:[x0,y0,x1,y1]` (entiers bornés, repère après EXIF), `language_hints:string[]`, `engine_receipt:{id,version,license,model_sha256}|null`, `mode:MANUAL|LOCAL_CPU|LOCAL_GPU`, `consent_receipt|null`, `max_pixels:int`. `OCRProposal/1` : `segments:[{id,bbox_oriented_px,text_nfc,confidence_nullable,edited_text_nfc,approved_bool}]`, `source_sha256`, `project_expected_sha256`, `preview_digest`, `status`, `warnings[]`. Confidence n'est jamais une probabilité calibrée sans protocole. Valeurs non finies, rectangles hors ROI, doublons d'ID, textes de contrôle actifs et résultats d'un autre SHA refusés.

États : `SOURCE_READY→ROI_SELECTED→ENGINE_READY|MANUAL_ENTRY→PROPOSAL→HUMAN_REVIEW→APPROVED→EXTERNAL_EXPORT_STAGED→EXPORTED`. Transitions `CANCELLED|STALE|REJECTED|ENGINE_UNAVAILABLE` non mutantes. Le texte proposé est une **surcouche de preview**, non un Subject/masque ni une modification de l'archive `.smartsvg` V1. Aucun nouveau writer ; si une future commande persiste du texte, exiger ADR V2 approuvée, migration explicite, CAS et Undo. Le bouton « Appliquer dans le projet » reste désactivé avec explication tant que G6.3 n'est pas implémenté.

Novice : sélectionner une zone d'affiche → transcription manuelle ou OCR local explicitement consenti → surligner chaque segment incertain → corriger au clavier → comparer original/proposition → choisir export externe provisoire ou conserver original. Expert : ROI EXIF, langues, version/hash/licence du moteur, rectangles et glyphes, diff visuel, source/révision, choix texte éditable externe vs chemins ; aucune substitution automatique. Barre contextuelle et canevas unique ; état vide, attente, moteur absent, erreur, annulation, focus visible, navigation clavier, contraste/mouvement réduit ; validation Windows 1366×768 et DPI 200 % à exécuter.

Le rendu de texte externe requiert police autorisée, glyphes complets, bidi/Unicode NFC et disposition explicite ; une police manquante bloque la promesse de fidélité. La sortie SVG d'édition n'est pas le SVG Basic Cut ; les quatre rôles demeurent PNG Print Then Cut, SVG Basic Cut, SVG CUT multicouche, SVG d'édition. Aucun texte ne devient CUT/SCORE par sa couleur. XML/DTD/URL/script sont refusés. Dimensions physiques en mm explicites, jamais déduites des PPP. Pas de réseau/téléchargement implicite ; CPU ou saisie manuelle sans GPU, RTX 8 Go seulement si moteur qualifié et consentement. Les médias, textes privés, modèles et polices sous licence ne sont pas ajoutés au dépôt.

## 3. Tests candidats et protocole (TOUS NOT_RUN)

Positifs : P1 fixture synthétique affiche FR accentuée + orientation EXIF 6, ROI et bbox remappées sans décaler le masque ; P2 correction manuelle et refus d'un segment produisent une preview fidèle à la décision ; P3 export externe SVG d'édition conserve le texte si licence et glyphes le permettent, Basic Cut convertit/refuse explicitement ; P4 relecture V1 préserve SHA, Subject et masques float32 ; P5 raccourcis/focus/Undo de brouillon sous Windows.

Négatifs : N1 OCR invente un mot et confiance élevée → pas d'approbation automatique ; N2 moteur absent ou licence inconnue → mode manuel, zéro réseau ; N3 ROI négative/hors image ou image > quota → refus sans mutation ; N4 EXIF changé entre sélection et réponse → STALE ; N5 glyphes absents ou texte bidi non pris en charge → blocage de fidélité, pas de substitution ; N6 DTD/XXE/script ou police externe → refus ; N7 SHA projet modifié en concurrence → pas de commit ni publication ; N8 annulation ou résultat tardif → proposition ignorée ; N9 crash/disque plein en staging → ancien export intact et nettoyage sûr ; N10 même nom export deux jobs → no-clobber ; N11 OCR du texte d'un client dans logs → test confidentialité négatif ; N12 import DS échoué ou coupe non mesurée → aucun PASS externe ; N13 tentative TextNode dans V1 → rejet sans migration silencieuse ; N14 altération alpha CUT par superposition texte → prévol bloque.

Fixtures : affiches et glyphes synthétiques FR/RTL, EXIF 1/6/8, 1/3/5 MP, boîtes de texte croisées, polices libres vérifiées, images corrompues, collisions et panne simulée ; ne pas inclure d'images de couverture sous droits. Mesurer latence p50/p95, pic RAM/VRAM, précision par langue et taux de correction humaine **sur corpus autorisé**, sans annoncer de seuil observé. Tests automatiques, UI Windows, GPU, Design Space et physique sont des axes séparés ; tous NOT_RUN ici.

TDD futur : (1) inventorier signatures réelles de tous ports et PR au SHA fixé ; (2) tests de validation ROI/EXIF et provenance ; (3) brouillon manuel sans modèle ; (4) adaptateur OCR facultatif après revue licence ; (5) relecture/preview/Undo de brouillon ; (6) sortie externe typée et prévol des quatre rôles ; (7) UI Windows/accessibilité ; (8) preuve DS/physique uniquement si scénario manufacturier. DoD : aucune mutation V1, aucun texte substitué sans approbation, erreurs actionnables, source et masques inchangés, non-régression des lots 12/13 et reçus de test exacts. Repli : mode manuel, source intacte, export bloqué si incertain.
