## Constat contradictoire vérifié
L'Atelier Tk affiche **le PNG d'aperçu du masque** du sujet (`subject.preview.png`), PAS les pixels de la source originale. `inspect_atelier_snapshot` construit cet aperçu depuis `project.mask_paths[mask.mask_id]`; `AtelierSubject` transporte `source_id`, `mask_id`, `bbox_px`, preuve et preview mais aucun octet de source. Une ROI dessinée sur ce viewport serait donc une ROI **dans le masque**, non une ROI OCR dans l'image source. Le bbox est une information de placement dans la source, pas une preuve que les dimensions du PNG masque correspondent à la source ni que l'image affichée représente des glyphes. **Refus explicite** de raccorder l'OCR à `NativeAtelierPanel.viewport` sans port source distinct, car cela fabriquerait un faux OCR de masque.
Le combobox de sujets et `render` déclenchent `viewport.load(None)` puis `viewport.load(PhotoImage(mask))`, détruisant toute ROI éphémère ; `load` ferme le panneau pinceau et renouvelle le snapshot. `brush_preview_request` ne s'ouvre qu'avec preuve float32 `verified`, projet absolu, SHA 64 hex et PNG borné ; ne jamais assouplir ces gardes pour OCR. `snapshot_mask_bindings` interdit de dériver un Subject ID de l'ordre des masques, du PNG 8 bits ou d'un hash. Le viewport utilise le drag gauche pour pan, `_show` recrée l'image Canvas, `fit_scale=None` et `1` correspondent tous deux à une source non réduite.

## Contrat candidat d'interface (NON IMPLÉMENTÉ)
`SourceRoiRequestV1` = `{project_id, expected_project_sha256, source_id, expected_source_sha256, source_width_px, source_height_px, roi_xywh_px:[x,y,w,h], viewport_generation, request_id, consent_provider_id?}`. Tous entiers pixels source, rectangle demi-ouvert, `0<=x<width`, `0<=y<height`, `w,h>0`, `x+w<=width`, `y+h<=height`. SHA en hex strict ; ID de requête unique ; snapshot source explicite. L'aperçu masque ne peut fournir `expected_source_sha256` et ne satisfait pas ce contrat. `SourceRoiResultV1` = `{request_id, source_sha256, project_sha256, roi_xywh_px, text_utf8, provider_id, provider_version, confidence?:number|null, status:PROPOSED|STALE|CANCELLED|FAILED}`. Confidence facultative, jamais convertie en preuve de fidélité. Le fournisseur OCR facultatif et sa licence doivent être vérifiés séparément. Pas de téléchargement ni réseau par défaut.
États : NO_SOURCE → SOURCE_READY → ROI_DRAFT → ROI_COMMITTED → OCR_PENDING → OCR_PROPOSED → USER_ACCEPTED_EXTERNAL / CANCELLED / STALE / FAILED. Le geste ROI est éphémère, réversible via Échap et Undo local de sélection ; aucun writer V1. Changement source, sujet, projet, SHA, taille ou génération viewport invalide les propositions. Zoom/pan après validation ROI conserve les coordonnées source déjà figées, mais invalide un drag en cours. Le résultat tardif ne peut être appliqué. Texte accepté est copié/exporté manuellement après confirmation de destination (écriture atomique, no-clobber).
UX : barre contextuelle `Déplacer | Sélectionner zone`, indicateur source et dimensions, poignées clavier/focus, retour `Zone invalide` explicite ; overlay sur le PNG source uniquement. 1366×768, DPI 200 %, contraste élevé et motion réduit à qualifier Windows. Pas de modal pour sélection locale, consentement explicite pour fournisseur externe ou export.
