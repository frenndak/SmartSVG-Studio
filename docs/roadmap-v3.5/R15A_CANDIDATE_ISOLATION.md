# R15-A — candidate-local failure isolation
A PR-specific detail, CI, review or comment collection failure now preserves the initial queue identity, discards all partial receipts for that candidate, and marks it unknown. Other verified PRs remain actionable. Unknown items conservatively consume WIP and suppress new-development capacity until a fresh complete observation. Global main/policy/rules/queue failure still invalidates the observation. Actual queue drift still follows the bounded restart protocol. No raw error bodies, new credentials, authority, or write operations. Synthetic tests cover partial failure, invalid provenance, remaining independent work and unchanged global fail-closed behavior.

The live R15_ROUTE_V1 envelope includes `candidate_failures` for unknown PRs with candidate-local collection errors. Only a number and fixed coarse reason are exported; raw response content and arbitrary error text are discarded. This diagnostic is a pointer for independent inspection and never frees capacity or establishes merge eligibility.
