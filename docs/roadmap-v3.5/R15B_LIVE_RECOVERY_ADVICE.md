# R15-B live recovery advice
The existing R15B_PILOT_V1 read-only packet now includes recovery for a nonterminal journal intent, derived from the existing recovery planner. It never selects a new candidate while an intent is pending. A changed journal ref, generation, intent, state or bytes discards advice. The recovery action is advisory only: PREPARED requalification, pending exact-main G0, repair/revert review, successor requalification, ambiguous negative readback or inspection. Neither this packet nor a negative readback proves terminal rejection. B still independently checks policy, current G0, journal CAS, semantic review and applicable authority. No journal write, retry or new merge authorization. This is a read-only operational bridge, not generalization beyond the first pilot.
