# R15-A — new-work advisory capacity
When the live queue is complete and no unknown scope exists, the legacy R15_ROUTE_V1 envelope now includes development_advice with available_slots, roles, reason and ADVISORY_ONLY qualification. The existing PR assignments are unchanged. At most 3 concurrent product PRs, one candidate per idle role, A first if a single slot and both idle. This is a suggestion, not a lease or authority to create a branch. A/B must read fresh main, live open queue, existing ownership and current roadmap dependencies and DoD; distinct scopes and fresh WIP checks before creating a PR. Never infer that a missing assignment reserves capacity. No action is required if advice is absent. Real persistent reservation and roadmap lot prioritization remain distinct future work. This avoids inventing PR IDs and preserves compatibility with the current pilot and legacy relay.
