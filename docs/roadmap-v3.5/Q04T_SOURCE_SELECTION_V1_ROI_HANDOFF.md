## Constat vérifié et contre-expertise
`select_source_png(project: LoadedProject) -> SourcePreview` parcourt `project.sources` **dans l'ordre**, prend le **premier PNG affichable** (si le résultat n'est pas `SOURCE_TOO_LARGE`), et retourne `status,png,source_id,width_px,height_px,subsample`. La vérification `verified_png_preview` contrôle la signature/IHDR, les dimensions déclarées et le SHA256 des octets source ; plafonds 8 MiB encodés, 5 millions de pixels, axe 4096. `subsample` est un facteur d'affichage calculé pour 480×235, **pas une nouvelle ressource PNG**. Si une source est `SOURCE_CHANGED`, `SOURCE_MISSING` ou `SOURCE_INVALID_PNG`, la sélection peut retourner immédiatement son échec, sans essayer une source valide suivante ; elle n'offre pas de sélection explicite par ID. Le SHA source est vérifié **en interne**, mais **absent du DTO `SourcePreview`**.
`load_native_preview(path)` obtient un projet V1 sain et son SHA d'archive via `_inspect_native_project_snapshot`, sélectionne l'image source, construit séparément l'Atelier, puis recontrôle le SHA d'archive avant de renvoyer `(state,preview)`. `state` contient `project_id`, comptes et éventuellement `atelier_snapshot`, mais le tuple n'est **pas** une preuve d'une identité OCR durable : aucune enveloppe `(source_sha,project_sha,source_id,viewport_generation)` n'est émise. Dans `_start_gui`, `LatestOnlyJob(load_native_preview)` refuse les réponses de génération obsolète, puis `receive` crée un `tk.PhotoImage` depuis `preview.png` et `preview_panel.load(original)`. Le shell affiche `source_id` et dimensions, pas un choix explicite de source ni une ROI. L'Atelier affiche un masque (Q04S) : **ne pas le réutiliser comme autorité de pixels OCR**. `LatestOnlyJob` ne prouve pas l'annulation effective d'un fournisseur OCR distinct.
### Décisions et alternatives
- **Retenir** le pipeline d'inspection V1, le PNG source vérifié et le viewport Tk existant. **Ajouter en conception seulement** une sélection explicite `source_id` parmi les sources admissibles, avec état de refus par source ; ne pas changer silencieusement la politique du premier PNG pour l'aperçu historique.
- **Contrat proposé** `VerifiedSourceRoiContext/1` : `{project_id,project_sha256,source_id,source_sha256,png_sha256,width_px,height_px,viewport_generation,roi_xywh_px,request_id}`. Les deux SHA PNG doivent être égaux pour ce flux non transformé ; SHA projet vient du snapshot V1 validé ; `source_id` et SHA source proviennent du même objet `LoadedProject.sources`, jamais d'une chaîne UI ni du masque. Rectangle source en pixels entiers, demi-ouvert, strictement borné. Tout changement de source, archive, viewport pendant drag ou worker invalide le contexte. Ce DTO **n'existe pas encore** ; localiser ses futurs consommateurs avant codage.
- **Refuser** l'option « lire directement `preview.source_id` et recalculer le SHA depuis le PhotoImage » : elle perd l'autorité archive, les octets originaux et la garantie de coordonnées. **Alternative minimale** : saisie manuelle de texte sur la source choisie, copie externe après revue ; OCR fournisseur local optionnel seulement après licence, consentement et gestion d'annulation. Aucun téléchargement par défaut.
- G6 texte éditable et migration V2 demeurent bloqués sans revue propriétaire ; G9 OCR avec validation humaine ne les satisfait pas. Quatre exports V3.4 restent distincts : PNG Print Then Cut, SVG Basic Cut, SVG CUT multicouche, SVG d'édition. Aucun export Cricut n'est produit par cette ROI.
## Parcours utilisateur et états
Novice : ouvrir projet → choisir explicitement « Image source » (pas masque) → sélectionner une zone → voir les coordonnées et une transcription manuelle/proposée → corriger → copier/exporter avec confirmation de destination. Expert : voir `source_id`, SHA abrégé, dimensions, mode PAN/ROI, provenance, erreurs et annulation. États `NO_PROJECT→VERIFIED_PROJECT→SOURCE_SELECTED→ROI_DRAFT→ROI_FROZEN→MANUAL|CONSENTED_OCR_PENDING→PROPOSED→REVIEWED→EXTERNAL_OUTPUT`, avec `STALE/CANCELLED/FAILED` non mutants. Undo local annule ROI ou correction, jamais un writer V1. Barre contextuelle plutôt qu'une nouvelle application ; focus clavier, Échap, 1366×768, DPI 200 %, contraste et motion réduit à qualifier en vrai Windows. Ne pas afficher de faux badge « certifié Cricut ».
