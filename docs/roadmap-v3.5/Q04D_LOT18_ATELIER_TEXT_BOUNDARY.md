## 2. Architecture et UX candidate : pas de second modèle de projet

Autorité : archive `smartsvg-project/1` avec `SourceAsset/Mask/Subject/Artifact`, writer et CAS ; `subject_id` et empreinte float32 pour retouches. La projection canevas/calques n'est pas un nouveau store. Le lot 18 cite `project_workspace_g22.py`, `project_archive.py`, `project_recovery.py`, `strokes.py`, `mask_binding_g33e.py`, `subject_identity_g33e.py` et `smartsvg_express_atelier_preview.html` : **chemins historiques cités, présence/ports HEAD à revalider avant codage**. L'adaptateur résout l'index de masque depuis l'identité sous SHA, jamais depuis le DOM.

Contrat transitoire **PROPOSÉ, non implémenté** : `TextDraftV1 {draft_id, project_sha256:hex64, text_nfc, font_ref, license_status:VERIFIED|UNKNOWN|RESTRICTED, missing_glyphs[], geometry_space:SOURCE_PX|OUTPUT_MM, output_role, operation:PREVIEW|EXPORT_ONLY}`. `output_role` est exactement l'un de PNG Print Then Cut, SVG Basic Cut, SVG CUT multicouche, SVG d'édition ; leurs QA et contrats restent distincts. Aucun champ `TextDraftV1` ne doit être ajouté à l'archive V1. Toute persistance éditable réclame une ADR de schéma/migration V2, revue propriétaire, compatibilité/rollback, tests Windows et G6.3 explicite. **Export-only = résultat partiel, jamais G6.3 PASS.**

États : `EMPTY → DRAFT → PREVIEW → REVIEWED → EXTERNAL_EXPORT` ; branches `STALE|CANCELLED|ERROR` sans mutation. Novice : ajouter texte, manipuler poignées et alignement, inspecter police manquante, aperçu avant/après, Undo local, avertissement « non rééditable après fermeture » et export volontaire. Expert : sélectionner Subject/chemin, lire SHA, coordonnées source px vs mm, topologie et licence ; aucun effet graphique ne devient CUT/SCORE/DRAW/FOIL. Le focus clavier, les raccourcis, la barre contextuelle, les états vides/pending/erreur, le contraste, 1366×768 et DPI 200 % sont **à éprouver**, pas certifiés. OCR sans modèle reste saisie/correction manuelle ; aucune installation/réseau automatique.
