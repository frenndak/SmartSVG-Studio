## 2. Architecture candidate et anti-régression

La **source de vérité** reste un seul projet .smartsvg V1 avec source SHA, subject_id et masques float32. Le catalogue et les presets ne deviennent pas un deuxième état métier ; ils décrivent les capacités et paramètres d'opérations **non mutantes**. Les jobs passent par l'orchestrateur prévu par la V3.4, conservent expected_revision, états `PLANNED/RUNNING/STALE/FAILED/CANCELLED/READY_FOR_REVIEW` et reçus durables. Une action de type Apply/Save n'est possible que par le writer/CAS existant sur une cible encore valide.

**Propositions de contrat, non classes existantes** : JobReceipt {job_id, source_sha, subject_ids, provider, model_sha, params_digest, status, output_refs}; Recipe {version, task, input_constraints, provider_reference, policy, user_confirmation}; ActionSuggestion {intent, safe_preview, assumptions, estimated_cost_unknown, reasons, requires_confirmation}. Champs de licence ou profil non vérifiés = UNKNOWN, jamais PASS. Les anciens modules `routing_v21121.py` et `quality_v21121.py` ne sont pas un agent décisionnel approuvé.

## 3. UX novice/expert et tests futurs (NOT_RUN)

**Novice :** « Réparer une zone » → sélectionner ROI → visualiser l'effet avant/après → accepter ou corriger ; « traiter 24 images » → liste d'entrées, progrès/échecs par fichier, bouton reprendre uniquement les éléments échoués ; assistant signale les étapes obligatoires sans tout exécuter. **Expert :** contrôler version/licence/hash, SHA de source, journal des jobs, taille VRAM/RAM et p50/p95 mesurés, dépenses matière et compatibilité comme UNKNOWN si absentes.

**Négatifs obligatoires :** (1) modèle annoncé mais poids absents ou hash différent → pas d'appel réseau ; (2) téléchargement refusé → usage manuel conserve ses fonctions ; (3) sortie repair appliquée sur projet révisé → STALE et zéro mutation ; (4) GPU OOM avec job annulé → pas de fuite d'objets ni projet corrompu ; (5) CSV avec formule ou traversal → traité en texte/entrée refusée, aucune exécution ; (6) batch 50 sujets interrompu → reprise 50/50 sans doublon, partition bornée par limites V1 ; (7) un preset obsolète avec modèle/licence changé → BROUILLON ou INVALID, pas de résultat prétendument équivalent ; (8) assistant propose d'effacer/écraser une sortie → exige prévol, destination et consentement, aucun workflow silencieux.

**Preuves distinctes** : tests unitaires de validation de catalogues, jobs et CSV ; UI Windows 1366×768/DPI 200 %, clavier/focus/reprise ; benchmark réel GPU/CPU seulement sur environnement attesté ; compatibilité Design Space/coupe physique uniquement pour sorties de fabrication aval. Crash/disk full/CAS concurrent et suppression de données privées nécessitent essais négatifs ; aucune preuve exécutée par ce document.

**État :** 12/12 fonctions D contre-expertisées en deuxième passage, 0/12 certifiées ; exigences historiques inchangées, 25 axes qualité préservés, aucun nouveau moteur/driver/format de projet ajouté. **Prochaine action V35-COV-18E-1** : examiner la famille E01–E20 par lots cohérents de 5 fonctions (bibliothèque, Atelier, accessibilité, QA, Windows), puis lier les 33 opportunités et préparer un audit croisé final.
