## Corrections transversales qui font autorité dans la candidate

1. Les anciennes tables HOSTILE rapprochent parfois un sujet d'un mauvais ticket (ex. catalogue→134, duplication→136, CommandPort→lot08). Les propriétaires corrigés ci-dessus et les DoD de leur **lot réel** prévalent ; les archives historiques restent inchangées.
2. V1 est le format existant, pas une interdiction d'implémenter le V2 déjà prévu au lot05. Les formulations « writer V1 uniquement » s'appliquent au chemin V1. Après migration explicite, writer V2 unique selon CP2 ; jamais deux autorités simultanées. L'historique éditable et la portabilité ne sont pas remplacés par des rapports externes.
3. La séparation locale initiale des tags/favoris est une tranche, pas l'abandon de F10. Une tranche de portabilité doit exporter/importer les préférences associées avec IDs, conflits, versions et consentement. Une référence à un chemin local seul ne satisfait pas ce DoD.
4. Réparer le lecteur d'écran et préserver les tailles d'écran/zoom héritées sont des obligations ; une technologie incapable doit fournir l'alternative accessible et rester non qualifiée sur cet axe. Le benchmark W13 décide le framework avant le gros éditeur.
5. Les priorités du registre source demeurent inchangées. Une sous-fonction P0 historique (admission, writer, resize CPU, etc.) ne devient pas P1/P2 parce que sa famille d'améliorations est planifiée plus tard. Les splits de DECISIONS D07 gouvernent D10 et les fonctions avancées.
6. **CAS V1 n'est pas un receipt durable.** Toute recette de cette table exigeant command_id/epoch, replay après perte d'ACK, Undo durable ou acceptation batch atomique complète dépend du writer transactionnel CP2/V2 qualifié. Le geste manuel et le CAS V1 existants restent utilisables avec leurs limites déclarées ; aucune équivalence exactly-once n'en est déduite. Après erreur de sauvegarde survenue après publication primaire, inspecter projet/backup/pending avant retry ; résultat indécidable = UNKNOWN_AFTER_INTERRUPTION. Cette précision reprend les revues horaires E07–E12 et SC-02A.
