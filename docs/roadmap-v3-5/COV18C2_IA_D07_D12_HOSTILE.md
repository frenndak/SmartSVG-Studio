## 2. Parcours utilisateur et source de vérité

**Novice** : importer → sélectionner/corriger directement → « Réparer localement » manuel → voir avant/après → Undo ; « améliorer avec IA » n'apparaît qu'avec capacité qualifiée, consentement éclairé et preview ; choisir un préréglage lisible, lancer une planche, voir statut par ligne et reprendre uniquement les échecs ; l'assistant explique les erreurs et propose une action réversible. **Expert** : inspecter source_sha, ROI en pixels source après orientation EXIF, version modèle et licence, budget CPU/GPU, recettes et digests, idempotency keys, rapport par unité et statut de preuve. UI : barre contextuelle du canevas, poignées, raccourcis, focus visible, erreurs localisées, état vide/pending/cancelled/stale ; test 1366×768, DPI 200 %, contraste et mouvement réduit à planifier. Pas de six boutons « Smart ».

**Source d'autorité** : un projet `.smartsvg` V1, source/Subject/masque float32, identité stable, SHA/CAS, writer/receipt existants. Les propositions, recettes, index, catalogues, rapports et sorties de batch sont **dérivés ou externes** ; aucun ne remplace le projet. La migration V2 n'est jamais implicite. Les quatre rôles de sortie restent distincts : **PNG Print Then Cut**, **SVG Basic Cut**, **SVG CUT multicouche**, **SVG éditable**. Un aperçu d'inpainting n'est pas un CUT certifié. Profil machine et opération CUT/SCORE/DRAW/PRINT/FOIL restent KNOWN/UNKNOWN sans commande inventée.

- `ResourceReservation{job_key,device:CPU|GPU,estimated_ram_bytes?,estimated_vram_bytes?,measured_peak_bytes?,budget_revision}` ; réservation avant lancement, un worker GPU qualifié à la fois jusqu'à benchmark. `OOM` → annuler/libérer, préserver brouillon, proposer CPU/manuel explicitement, pas de boucle de retry.
