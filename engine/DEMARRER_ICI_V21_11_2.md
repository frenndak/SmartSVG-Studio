# SmartSVG V21.11.2 — Démarrer simplement

**1.** Fermer ComfyUI, conserver une copie des anciens workflows, puis installer cette version seule dans `custom_nodes`.

**2.** Ouvrir `example_workflows/SmartSVG_Studio_V21_11_2_00_Diagnostic.json` pour vérifier les capacités sans exécuter d'IA.

**3.** Pour un dessin simple, ouvrir `..._01_Express_Auto_Deux_Etapes.json`, importer l'image et exécuter. Pour une planche, choisir `..._02_Planche_Corriger_Exporter.json` ; pour une capture d'écran, choisir `..._03_Capture_Guidee.json` (export désactivé jusqu'à validation).

**4.** Avant toute découpe, consulter les anomalies, vérifier le masque et la taille, puis importer uniquement le PNG du dossier `00_IMPORTER_DANS_CRICUT` comme **Image aplatie / Imprimer puis découper**.

Consulter `GUIDE_INSTALLATION_V21_11_2.md` pour les précautions et tests.
